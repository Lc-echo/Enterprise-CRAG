星辰科技信息安全管理规范（2026版）

一、数据分类与保密等级
公司数据分为四个保密等级：
1. 公开级（C1）：可对外发布的信息，如官网内容、公开新闻稿。
2. 内部级（C2）：仅限公司内部查阅，如内部通知、部门周报。
3. 机密级（C3）：仅限授权人员访问，如客户数据、财务数据、技术方案。
4. 绝密级（C4）：仅限高管和指定负责人访问，如核心算法、融资信息。

二、账号与权限管理
1. 所有系统账号必须启用双因素认证（2FA）。
2. 密码策略：至少12位，包含大小写字母、数字和特殊字符，每90天强制更换。
3. 离职员工账号必须在离职当天由IT部门禁用，24小时内彻底删除。
4. 生产环境访问权限需经安全部门审批，实行最小权限原则。

三、代码安全
1. 所有代码必须经过 Code Review 方可合入主分支。
2. 禁止在代码中硬编码密钥、密码等敏感信息，统一使用密钥管理服务（KMS）。
3. 依赖库必须经过安全扫描（Snyk），发现高危漏洞需在48小时内修复。
4. 每季度进行一次全量代码安全审计。

四、数据安全
1. 客户数据存储必须加密（AES-256），传输必须使用 TLS 1.3。
2. 数据库备份策略：每日增量备份，每周全量备份，异地容灾。
3. 敏感数据（如身份证号、手机号）必须脱敏处理后方可用于测试环境。
4. 严禁使用个人U盘、网盘等工具传输公司数据。

五、安全事件响应
1. 发现安全事件应立即报告安全部门（security@startech-example.com，内线 8900）。
2. 安全事件响应时间：P0级（数据泄露）15分钟内响应，P1级1小时内响应。
